        function drawDetectionDistributionCanvas({
            canvas,
            timeResolution,   // tSteps
            d,
            k0,
            sigma = 1,
            tMin = 0,
            tMax = 20,
            L = 10,
            ySteps = timeResolution
            }) {
            const ctx = canvas.getContext("2d")

            const width = canvas.width
            const height = canvas.height

            const tSteps = timeResolution
            const dt = (tMax - tMin) / (tSteps - 1)
            const yMin = -L
            const yMax = L
            const dy = (yMax - yMin) / (ySteps - 1)

            const grid = new Array(tSteps * ySteps)
            let maxW = 0

            for (let i = 0; i < tSteps; i++) {
                const t = tMin + i * dt

                for (let j = 0; j < ySteps; j++) {
                    const y = yMin + j * dy
                    const x = L

                    const w = boundaryFlux(x, y, t, d, sigma, k0, "right")

                    grid[i * ySteps + j] = w
                    if (w > maxW) maxW = w
                }
            }

            const image = ctx.createImageData(width, height)
            const data = image.data

            for (let px = 0; px < width; px++) {
                const i = Math.floor((px / (width - 1)) * (tSteps - 1))

                for (let py = 0; py < height; py++) {
                const j = Math.floor(((height - 1 - py) / (height - 1)) * (ySteps - 1))

                const w = grid[i * ySteps + j]

                // Gråskala: svart = lav sannsynlighet, hvit = høy
                const intensity = maxW > 0
                    ? Math.floor(255 * Math.sqrt(w / maxW))
                    : 0;

                const idx = 4 * (py * width + px)
                data[idx + 0] = intensity
                data[idx + 1] = intensity
                data[idx + 2] = intensity
                data[idx + 3] = 255
                }
            }

            ctx.putImageData(image, 0, 0)
        }

overview

renderFig1() is just a wrapper function and a little bit useless if i'm completely honest. It calls drawDetectionDistributionCanvas() passing the canvas to draw on, resolution, some global variables and the time interval.

drawDetectionDistributionCanvas() creates an array of size resolution x resolution, meaning the 'image' it produces is square regardless of the aspect ratio of the canvas on screen. This array is in practice a resolution x resolution matrix but is stored as a one dimensional array. For each point in this array it calls boundaryFlux() passing its y and t value (x is always 10)

boundaryFlux then sends its arguments on to psiAndGradAt() to get psi norm squared and stores it as rho (psiAndGradAt is explained here) then gets velocity at that point by calling velocityRaw() (which does the same as velocityAt() except it doesn't clamp the velocity). the probabilityFlux is then given by:
\rho = |\Psi|^2,\qquad \mathrm{flux} = \rho v_n
where v_n is the velocity component normal to the boundary, in the case of the screen at x=10, this is:
J_x = \rho v_x

That value is stored as a weight (w) for that pixel (x,y) and, if that value is the greatest value seen yet, stored as maxW. when all pixels have been given a weight, their respective values are converted to a number between 0-255, where maxW = 255 and 0 = 0, and drawn to canvas as rgb(w,w,w).
