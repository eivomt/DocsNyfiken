making waves

svgGenerator.py

If you want to create SVG's of other sine waves, change the wavelength array and run the script. 

            wavelengths = [27835.15, 11321.62, 5914.97, 3300.76, 1819.99, 924.21, 384.09, 92.42, 38914.28, 16227.63, 8770.08, 5134.52, 3042.68, 1738.67, 902.77, 380.34, 92.20]


            for wavelength in wavelengths:
                sine_to_svg(wavelength/2,100,600,100,'./waveSVG/' + str(wavelength) + '.svg')
It will loop through all wavelengths in the array and create a new SVG, name them whatever wavelength you've provided (in nanometers) and store it in ./waveSVG/. Note, relative path to whereever you run the script from. 

            Parameters :

            wavelength : float
                Distance (in SVG pixels) for one full 2π sine cycle along the x-axis.
            amplitude : float
                Peak height of the wave (in SVG pixels). The wave is centered vertically.
            x : int or float
                SVG width in pixels.
            y : int or float
                SVG height in pixels.
            filepath : str, optional
                Where to write the SVG. Defaults to "sine.svg".
