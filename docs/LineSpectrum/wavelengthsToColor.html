From Wavelengths to Colours

hydrogen.js

Having calculated the wavelengths emitted by hydrogen, the next step is to convert those wavelengths into colours that can be displayed by a browser. While physicists typically describe light in terms of wavelength, computer graphics systems represent colour using combinations of red, green, and blue (RGB) intensities.

The purpose of this script is therefore to transform a wavelength expressed in nanometres into a colour that can be rendered on screen, and then use that colour to create spectral lines corresponding to the hydrogen emission spectrum.

Converting Wavelength to RGB

The function wavelengthToRGB() approximates the visible spectrum by mapping wavelengths in the range 380–780 nm to RGB values. 

        function wavelengthToRGB(lambda) {
            let R=0, G=0, B=0;

            if (lambda >= 380 && lambda < 440) { R = -(lambda - 440) / (440 - 380); G = 0; B = 1; }
            else if (lambda >= 440 && lambda < 490) { R = 0; G = (lambda - 440) / (490 - 440); B = 1; }
            else if (lambda >= 490 && lambda < 510) { R = 0; G = 1; B = -(lambda - 510) / (510 - 490); }
            else if (lambda >= 510 && lambda < 580) { R = (lambda - 510) / (580 - 510); G = 1; B = 0; }
            else if (lambda >= 580 && lambda < 645) { R = 1; G = -(lambda - 645) / (645 - 580); B = 0; }
            else if (lambda >= 645 && lambda <= 780) { R = 1; G = 0; B = 0; }
            else { R = G = B = 0; } // out of range = black

            // Intensity factor near vision limits
            let S = 1;
            if (lambda > 700) {
                S = 0.3 + 0.7 * (780 - lambda) / (780 - 700);
            } else if (lambda < 420) {
                S = 0.3 + 0.7 * (lambda - 380) / (420 - 380);
            }

            // Gamma correction
            const gamma = 0.8;
            const to8bit = v => Math.round(255 * Math.pow(v * S, gamma));

            return {
                r: to8bit(Math.max(0, Math.min(1, R))),
                g: to8bit(Math.max(0, Math.min(1, G))),
                b: to8bit(Math.max(0, Math.min(1, B))),
            }
        }

The visible spectrum is divided into several wavelength intervals. Within each interval, the red, green, and blue components are interpolated to produce a smooth transition between neighbouring colours.

Two additional corrections are applied. First, wavelengths near the limits of human vision are assigned a reduced intensity, reflecting the lower sensitivity of the eye in those regions. Second, a gamma correction is applied to produce colours that appear more natural on a display.

The output is an object containing red, green, and blue values in the range 0–255.

Converting RGB to HSL

While RGB is suitable for displaying colours, it is not particularly convenient when different brightness levels of the same colour are required. For the glow effect used by the spectral lines, it is preferable to work in the HSL colour space.

HSL represents colour in terms of:

  • Hue — the colour itself
  • Saturation — the colour intensity
  • Lightness — the brightness of the colour

The conversion is performed by the function: 

        function RGBToHSL(r,g,b) {
            r/=255; g/=255; b/=255;
            const cmin=Math.min(r,g,b), cmax=Math.max(r,g,b), delta=cmax-cmin;
            let h=0, s=0, l=(cmax+cmin)/2;
            if (delta !== 0) {
                if (cmax === r) h = ((g-b)/delta) % 6;
                else if (cmax === g) h = (b-r)/delta + 2;
                else h = (r-g)/delta + 4;
                h = Math.round(h*60); if (h<0) h+=360;
                s = delta === 0 ? 0 : delta / (1 - Math.abs(2*l - 1));
            }
            return { h, s: +(s*100).toFixed(1), l: +(l*100).toFixed(1) };
        }

Once converted to HSL, the lightness component can be varied independently while preserving the hue and saturation of the original colour.

Creating a Glow Effect

To produce the appearance of a luminous spectral line, three brightness levels of the same colour are generated. These represent the outer glow, the main line, and the bright central core. 

        function makeTripletFromHSL({h, s, l}) {
            const clamp = v => Math.max(0, Math.min(100, v));
            const outer = `hsl(${h} ${s}% ${clamp(l - 15)}%)`;
            const mid   = `hsl(${h} ${s}% ${clamp(l)}%)`;
            const inner = `hsl(${h} ${s}% ${clamp(l + 25)}%)`;
            return { outer, mid, inner };
        }

The resulting colour triplet is later applied to nested HTML elements, creating the layered appearance of a glowing emission line.

Positioning Spectral Lines

Visible wavelengths occupy only a finite interval of the electromagnetic spectrum, approximately 380–780 nm. Within the interface, this range is represented by a vertical spectrum bar.

To place a spectral line in the correct location, its wavelength is mapped onto a percentage of the container's height: 

        function nmToPercent(nm){
            const min = 380, max = 780;
            return 100 - ((nm - min) / (max - min)) * 100;
        }

Short wavelengths are placed near the ultraviolet end of the spectrum, while longer wavelengths are positioned closer to the infrared end.

Creating Spectral Lines

Once the colour and position have been determined, a spectral line can be added to the display. 

        function addSpectralLine(container, triplet, nm) {
            const line = document.createElement('div');
            line.className = 'spectral-line';
            line.style.setProperty('--outer', triplet.outer);
            line.style.setProperty('--mid',   triplet.mid);
            line.style.setProperty('--inner', triplet.inner);

            line.style.top = nmToPercent(nm) + '%';    // place within the container

            const mid = document.createElement('div');
            mid.className = 'spectral-mid';
            const inner = document.createElement('div');
            inner.className = 'spectral-inner';
            mid.appendChild(inner);
            line.appendChild(mid);
            line.classList.add('hidden')

            container.appendChild(line);
        }

The function creates the required HTML elements, assigns the colour triplet as CSS variables, positions the line within the spectrum bar, and inserts it into the document. Newly created lines are initially hidden and become visible when the corresponding electronic transition is selected by the user.
