User

After a superuser has connected, all following connections are users. If the superuser ever disconnects, that's a problem btw, to fix this any user can type 'disconnectAll()' in the console to close all connections to the server. Then whoever connects first is once again the superuser (kind of a wonky system but it works).

anyways - users

Users have only one possible action, they can collapse the superposition to a definite outcome by clicking the coin. Doing so results in the screen going completely blue or red, stopping the stroke animation and displaying only one of the SVG's, heads or tails.

stroke animation

adding a stroke animation to all paths in the SVG's is done in this block: 

        paths.forEach((path, index) => {
            const length = path.getTotalLength();

            path.style.strokeDasharray = length;
            path.style.strokeDashoffset = length;

            const animationName = `kron-${index}`;

            const styleSheet = document.styleSheets[0];
            styleSheet.insertRule(`
                    @keyframes ${animationName} {
                        from {
                            stroke-dashoffset: ${length}
                        } to {
                            stroke-dashoffset: 0;
                        }
                    }
                `, styleSheet.cssRules.length);

            path.style.animation = `${animationName} 4s ease-in-out infinite alternate`;
            path.style.animationDelay = '2.75s'
        });

for each path we compute its length. Create an animation rule and give it an indexed name (because length varies). animate stroke-dashoffset from total length to 0 and make it go back and forth forever (infinite alternate).

collapse

Collapsing the 'wave function' is done by calling either cutToBlue() or cutToRed(), lets look at blue as our example (they are identical except color and which SVG is shown) 

        cutToBlue = () => {
            Mynt.classList.add('hidden')
            Kron.classList.add('hidden')

            coinContainer.classList.add("hard-blue")
            coin.removeEventListener("click", sendCoinClick)

            setTimeout(() => {
                            
                for (let i = 0; i < myntPaths.length; i++) {
                    myntPaths[i].style.animation = 'none'
                    myntPaths[i].style.strokeDasharray = length;
                    myntPaths[i].style.strokeDashoffset = 0;
                }

                for (let i = 0; i < kronPaths.length; i++) {
                    kronPaths[i].style.animation = 'none'
                }
                
                Mynt.classList.remove('hidden')
                
                
                collapsed = true
            }, 200);
        }

Walkthrough:
Hide both SVG's.
Give background element a class which sets the background-color.
After 200 milliseconds remove offset for all paths in the relevant SVG.
Stop the animations for both SVG's.
Remove the class which hides the SVG we want to show.
Set the boolean collapsed to true, used elsewhere probably.
The gradual fade of the SVG is thanks to CSS and comes automatically from adding or removing the class 'hidden'.

case 'coin_clicked'

When a user sends a message to the server: 'coin_clicked', the server will respond by running the following block: 

            if data.get("type") == "coin_clicked":
                sender_ws = websocket
                sender_id = connected_clients[sender_ws]["id"]

                partner_ws = get_partner(sender_ws)
                if partner_ws is None:
                    await sender_ws.send(json.dumps({
                        "type": "coin_clicked",
                        "inGroup": False
                    }))
                    continue

                partner_id = connected_clients[partner_ws]["id"]
                pair_key = get_pair_key(sender_ws, partner_ws)

                first_measurement = False

                if Entangled:
                    if pair_key not in pair_states:
                        base = random.choice([0, 1])
                        pair_states[pair_key] = {"collapseTo": base}
                        value = base
                        first_measurement = True
                    else:
                        base = pair_states[pair_key]["collapseTo"]
                        value = 1 - base if Opposite else base
                else:
                    value = random.choice([0, 1])

                collapsed_values[sender_id] = value

                await sender_ws.send(json.dumps({
                    "type": "coin_clicked",
                    "inGroup": True,
                    "partner": partner_id,
                    "value": value,
                    "firstMeasurement": first_measurement
                }))

walkthrough
It stores the id of whatever user sent the message
Checks if the sender is in a pair, if not it takes no further action
Stores the id of the user paired to sender
Checks whether the pair is entangled
If not, it chooses between 0 and 1 with a random number generator
If it is though:
Checks if this is the first collapse of the pair.
If the paired user has already collapsed its wave function the server replies the opposite value if opposite is true and the same value if opposite is false (0 or 1)
If this is the first measurement of the pair, it chooses between 0 and 1 with a random number generator
Either way the value is stored and sent back in JSON of type "coin_clicked" which prompts client action

client action

User gets a JSON back of type 'coin_clicked' and runs the following block: 

        case 'coin_clicked':
            console.log('data.value = ' + data.value)
            if (!superUser) {
                console.log('Measured first')
                console.log('Recieved: ' + data.value + ' from server')
                if (data.value === 1) {
                    console.log('Displaying red')
                    cutToRed()
                } else if (data.value === 0) {
                    console.log('Displaying blue')
                    cutToBlue()
                }
            }
        break

Client side is straight forward, if it gets a 1 back in data.value, call cutToRed() if 0 cutToBlue()
Along with a bunch of debug logs which should probably be removed at this point.

case 'reset' - back to superposition

When a superuser presses the button 'reset measurements' it sends "reset-all" to the server, prompting it to run this block: 

        if data.get("type") == "reset-all":
            pair_states.clear()
            collapsed_values.clear()
            for client, info in connected_clients.items():
                try:
                    await client.send(json.dumps({"type": "reset"}))
                except Exception as e:
