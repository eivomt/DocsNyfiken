server restart

If the server is down you'll have to restart the process.
connect via ssh and navigate to /home/ubuntu.
/home/ubuntu should be your working directory when you connect, you can make sure by running pwd 

            ubuntu@nyfiken:~$ pwd
                /home/ubuntu
from run tmux 
            ubuntu@nyfiken:~$ tmux
you will get a new terminal you can detach from, inside activate the environment and run the server: 
            source ~/wsenv/bin/activate
            python server.py
detach by presing 
            Ctrl+b then d
you can reconnect later by running 
            ubuntu@nyfiken:~$ tmux attach
All print commands prints to this session.
or stop the session by running 
            ubuntu@nyfiken:~$ tmux kill-session
