Entanglement

A tool for teaching the properties of entangled particles. Users connect to a server and has the option of 'tossing a coin', getting either heads or tails back, analogous to collapsing the wavefunction. The visualization requires a minimum of three participants, whoever connects first becomes a superuser. The superuser sets the parameters of the coin toss, the parameters are:

Entangled, true : false
Opposite, true : false

If entangled is true, the outcome of one coin toss decides the outcome of the other. If opposite is true and one coin is measured as heads, the other is guaranteed to come up tails, if opposite is false, the second measurement is the same as the first. If entangled is false, the outcome of one coin toss has no bearing on the other and both users are measuring heads or tails with a 50% probability each time.
The game is for the users to guess the parameters set by the super user.
How many times do you get outcomes aligning with your assumption before you can be certain of how the game is rigged.
