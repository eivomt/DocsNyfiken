Super user

Super user has control over the settings for the visualization for each connected user. Possible actions for the super user are toggling opposite and entangled. Setting all users back to superposition and disconnecting all users.

super user can at all times see how many clients are connected and their status (collapsed?).

Users are paired in two's so that the measurement of one user is entangled only to whoever was paired up with them initially. The pairs are made chronologically, a user is paired with the next one to connect or the previous depending on the number of already connected clients (odd / even). If a user is not connected to another, collapse is disallowed. The number preceding user id's in the list of connected clients represents what pair the user belongs to.

superUser is set to true, all svg's are removed (display set to none) and super user controls are shown. These are in DOM for all users, just not visible and they have no eventListeners until becomeSuper() is called

when the server gets a message of type 'request-id-list' the following block runs: 

        if data.get("type") == "request-id-list":

            await websocket.send(json.dumps({

which returns an array of hashmaps containing the id of all connected clients (except the superuser) along with their values (0 for blue, 1 for red). If a user has not yet collapsed into a definite state, value is returned as a string "Superposition". Handling this information and converting it to UI elements is done in recievedID(). 

        let recievedID = (clients) => {
            const table = document.querySelector('.connected-clients');

            const existingRows = table.querySelectorAll('tr');
            existingRows.forEach(row => row.remove());

            let group = 0
            clients.forEach((client, index) => {
                const tr = document.createElement('tr');

                if(index%2==0) {
                    group++
                }

                const tdId = document.createElement('td');
                // tdId.textContent = `${index + 1}: ${client.id}`;
                tdId.textContent = `${group}: ${client.id}`;
                tdId.style.paddingLeft = '1rem';

                const tdLed = document.createElement('td');
                tdLed.classList.add('led-td');

                const ledDiv = document.createElement('div');
                ledDiv.classList.add('collapsed-led');

                if (client.value === 'Superposition') {
                    ledDiv.classList.add('ledW');
                } else if (client.value === 0) {
                    ledDiv.classList.add('ledB');
                } else if (client.value === 1) {
                    ledDiv.classList.add('ledR');
                }

                tdLed.appendChild(ledDiv);

                // Append columns to row
                tr.appendChild(tdId);
                tr.appendChild(tdLed);

                // Append row to table
                table.appendChild(tr);
            });

            // Show table if hidden
            table.style.display = 'table';
        }
