step()

For reasons which are, frankly, beyond me, evolving the wave function in imaginary time has the effect of \psi converging on its ground state. Confusing, but very useful. Since the particles mass is a dynamic variable set by user input, we cannot simply hard code the ground state. Whenever mass is changed we run step() until the wavefunction has converged close enough to the new ground state, before we activate 'normal' time evolution in unitaryStep()
