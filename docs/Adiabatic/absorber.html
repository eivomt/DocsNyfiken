Absorber

If the potential well is moved quickly, parts of the wavefunction will escape the well and move off in one direction or the other. In reality that part of the wavefunction should continue flying off in perpetuity. This simulation however, is not reality, and if we allowed this to play out undisturbed the wavefunction would 'loop around' the x-axis -L/2 becoming L/2. For example, if it reached the left edge it would disappear to the left and reappear on the right, causing all kinds of strange interference effects. While this looks cool, this is too far from the actual physics of our setup and here function must precede form.

Although the 'correct' solution to this is an infinite x-axis, that solution is infeasible computationally, as one time step would, quite literally, take forever to carry out. We fix this by introducing an absorber function, by convention named Gamma, whose job it is to 'eat' the wave function as it approaches the end of its little world. Each time step every y-value of the wavefunction (separated by dx) is subtracted the value of Gamma
\psi(x) \to \psi(x) - \Gamma(x)
Gamma could be any function of x, in this implementation we've used a piecewise second degree polynomial, multiplied by a scaling factor gamma0 and split, so that Gamma equals 0 inside an interval where the absolute value of x is less than or equal to:
