Bound states

A visualization of a wavefunction defined as a superposition of the allowed bound states of a potential well, evolving in time. Users can interact with the visualization by setting the probability of each bound state and by making a measurement, at which point the wavefunction collapses into one of the, in this case 6, allowed states. Each measurement made is stored and shown in a GUI element, visually identical to the probability control, the educational point being that, although it is impossible to predict what state a wave function in a superposition will collapse to, as the number of measurements increases, the distribution of measurements will converge on the probability distribution set by the user. The option is also provided, to make 5 measurements at once. Added to make arriving at a measurement distribution which reflects the probability distribution less tiresome, once the point of collapsing into a single state has been made.

Here the plots are made with p5js, and so uses a conventional p5js flow. function setup() is run once and initializes the canvas, while function draw() is run every frame and updates the plot continuously.
