Computing bound states

Energies.py is a barely modified version of Excercise_3_1_2.py , a script from Sølve Selstø's book, A computational introduction to quantum physics . It returns the bound energies and eigenstates for a given potential well. In energies.py these are written to csv files which are in turn read by javascript. The python script plays no active part in the interface and could be left out, but if you would like to change the potential well you would have to change it here and run the script to write new csv's.

the script writes four csv files, containing;

  • eigenvalues
  • eigenvectors imaginary part
  • eigenvectors real part
  • potential well

defining the well

If you would like to change the potential, play around with: 

        Input for the confining potential:
            V0      - The "height", the the barrier (must be negative for a well)
            w       - The width of the barrier
            s       - Smoothness parameter, rectangular well for s -> infinity

And run energies.py to generate new csv files.
The current chosen parameters for the well are: 

            # Physical parameters:
            V0 = -4
            s = 5
            w = 6
which gives this function for the potential. A finite rectangular well, with smoothed edges.
