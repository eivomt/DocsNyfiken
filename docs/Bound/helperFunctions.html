Helper functions

calculateSum() adds together all values in an array and returns the total. It is used when normalizing probabilities and slider inputs.


normalize() divides every value in an array by the array's total sum. This ensures all values add up to 1 and can be interpreted as probabilities.


recalculateAmplitudePositions() converts the normalized probabilities into cumulative probability intervals. These intervals are later used to randomly select an energy level during measurement according to the Born rule.


recalculateProbabilities() reads the slider values, stores them in probabilityArray, normalizes them, and updates the cumulative probability intervals used for measurements.


resizeMeasurements() updates the heights of the measurement bars. It reads the number of recorded measurements, normalizes them, and rescales the bars so their relative heights reflect the observed frequencies.


renormalizeInput() rescales all slider values so that their total becomes 100. This ensures the state coefficients remain properly normalized after user interaction.


setEquationValue() updates the displayed mathematical expression for the state. It can either show the compact summation form \Psi_s = \sum_{i=0}^{5}\alpha_i\psi_i or expand it into the individual weighted energy eigenstates.
