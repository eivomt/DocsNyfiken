Setup

setup() performs the one-time initialization of the simulation. It creates the canvas, sets the frame rate, defines the numerical domain used for the position and momentum calculations, and assigns the initial parameters of the Gaussian wave packet.

The variables Lx, Lp and N define the computational grid: the extent of the position and momentum domains and the number of sample points used in the numerical calculations. The packet is initially given a mean position x₀ = 5, a mean momentum p₀ = -4, and a position uncertainty σₓ = 3. The momentum uncertainty is then calculated from \sigma_p = \frac{1}{2\sigma_x} corresponding to a minimum-uncertainty Gaussian state.

The function also configures the user interface by setting slider limits, step sizes, initial values and tick labels. The position and momentum sliders span the interval [-20, 20], while the width slider is constrained to the range defined by SigmaXMin and SigmaXMax.

The initial values of x₀ and p₀ are intentionally chosen to be non-zero. This avoids a small visual misalignment of the slider thumbs that occurs when both sliders are initialized exactly at zero.

Finally, drawPosition() and drawMomentum() are called to generate the initial position-space and momentum-space distributions before the animation begins. 




        function setup() {
            createCanvas(windowWidth, windowHeight)
            background(230)
            frameRate(24)
            
            // Numerical grid parameters
            Lx = 50
            Lp = 10
            N = 1000
            
            // Inputs for Gaussian
            p0=-4
            SigmaX = 3
            SigmaP = 1/(2*SigmaX)

            SigmaXMax = 5
            SigmaXMin = .1
            
            // Initial mean position
            x0 = 5
            
            // Window fixation values
            xMin = -Lx/2
            xMax = Lx/2
            yMin = -1.00
            yMax = 1.00

            positionHeight = -350
            momentumHeight = 125

            document.getElementById("position-tick-numbers").style.top = (windowHeight/2  + 65 + (positionHeight /2)).toString() + "px"
            document.getElementById("momentum-tick-numbers").style.top = (windowHeight/2  + 65 + (momentumHeight /2)).toString() + "px"
            
            let positionSlider = document.getElementById("position")
            let momentumSlider = document.getElementById("momentum")
            let sigmaXSlider = document.getElementById("sigmax")
            
            sigmaXSlider.max = SigmaXMax
            sigmaXSlider.min = SigmaXMin
            
            positionSlider.step = .001
            momentumSlider.step = .001
            sigmaXSlider.step = .001
            
            sigmaXSlider.value = (SigmaXMax + SigmaXMin)/2
            
            positionSlider.min = -20
            positionSlider.max = 20
            momentumSlider.min = -20
            momentumSlider.max = 20


            positionSlider.value = x0.toString()
            momentumSlider.value = p0.toString()
            
            document.getElementById("x-min").innerHTML = -20
            document.getElementById("x-max").innerHTML = 20
            document.getElementById("p-min").innerHTML = -20
            document.getElementById("p-max").innerHTML = 20
            document.getElementById("sigmaX-min").innerHTML = SigmaXMin.toString()
            document.getElementById("sigmaX-max").innerHTML = SigmaXMax.toString()
            
            drawPosition()
            drawMomentum()
        }
