drawMomentum() and drawMomentumEnvelope() are identical to their position counterparts except for the variables SigmaP and p0 being swapped out for SigmaX and x0. So, I will go through drawMomentum() and drawMomentumEnvelope() but not the others.

drawMomentum()

drawMomentum() draws the momentum-space wave function. It first translates the origin to the center of the momentum graph It then loops from x_{min} to x_{max} , using each value as a momentum value p . For each point it draws: \frac{1}{\sigma_p\sqrt{2\pi}} e^{-\frac{(p-p_0)^2}{2\sigma_p^2}}\cos(x_0p) multiplied by a scalar in each direction so the graph fills the screen nicely
Here p_0 is the mean momentum, \sigma_p is the momentum standard deviation, and x_0 controls the oscillation through the cosine term. The exponential term gives the Gaussian envelope, while \cos(x_0p) gives the oscillating real part inside that envelope. After drawing, the function translates the origin back to its original position. 

        let drawMomentum = () => {
            translate(windowWidth/2, (windowHeight + momentumHeight)/2)
            beginShape()
            for(let i=xMin; i <= xMax; i+=.005) {
                vertex(i*(windowWidth/Lx), -1 * 40*(1/ (SigmaP * Math.sqrt(2 * Math.PI))) * (Math.E**(-1 * (i - p0)**2 / (2*SigmaP**2)) * Math.cos(x0*i)))
            }
            endShape()
            translate(-windowWidth/2, -1*(windowHeight + momentumHeight)/2)
        }

drawMomentumEnvelope()

drawMomentumEnvelope() is the same as drawMomentum(), but without the cosine term. This means it only draws the Gaussian envelope: \frac{1}{\sigma_p\sqrt{2\pi}} e^{-\frac{(p-p_0)^2}{2\sigma_p^2}} . It represents the overall shape and amplitude limit of the momentum distribution, centered around p_0 , with width controlled by \sigma_p. 

        let drawMomentumEnvelope = () => {
            translate(windowWidth/2, (windowHeight + momentumHeight)/2)
            beginShape()
            for(let i=xMin; i <= xMax; i+=.005) {
                vertex(i*(windowWidth/Lx), -1 * 40*(1/ (SigmaP * Math.sqrt(2 * Math.PI))) * (Math.E**(-1 * (i - p0)**2 / (2*SigmaP**2))))
            }
            endShape()
            translate(-windowWidth/2, -1*(windowHeight + momentumHeight)/2)
        }

Notice that as x0 or p0 shifts it has no effect on the envelope of the other but it does change the oscillatory frequency of the real (and imaginary) part of the wave function. Meaning, while the wave function does change, the probability distribution does not. 





        function draw() {
            let positionSlider = document.getElementById("position")
            let momentumSlider = document.getElementById("momentum")
            let sigmaXSlider = document.getElementById("sigmax")

            let bgColor = color('#F1F1F1')
            let white = color("#FFF")
            let blue = color(32,115,232)
            let red = color(252,65,32)
            let range = chroma.scale(['#2073E8', '#FFF', '#FC4120']).mode('lab')

            x0 = positionSlider.value
            p0 = momentumSlider.value
            SigmaX = sigmaXSlider.value
            SigmaP = 1/(2 * SigmaX)

            // console.log(range(SigmaX/5))
            sigmaXSlider.style.setProperty('--thumb-color', range(SigmaX/5))


            background(bgColor)
            strokeWeight(3)
            stroke(32,115,232)
            drawPosition()
            stroke(252,65,32)
            drawMomentum()
            strokeWeight(4)
            stroke(32,115,232)
            drawPositionEnvelope()
            stroke(252,65,32)
            drawMomentumEnvelope()
            drawTicks()
        }
