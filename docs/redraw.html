Redraw

redraw() is called when the diagram needs to be rebuilt, for example after user input changes parameters such as slit distance or wavelength.

overview

The function first checks whether a redraw is already in progress. If so, it returns immediately. This prevents overlapping redraw operations. 

        if (drawing) return

It then stops the measurement animation by setting fire to false, and marks drawing as true while the diagram is being rebuilt. 

        fire = false
        drawing = true

The canvas is cleared, and resizeCanvas() is called so the canvas dimensions match the current window size. 

        cnvContext.clearRect(0, 0, canvas.width, canvas.height)
        resizeCanvas()

Existing SVG circles and lines are then selected and removed. This clears the previously drawn static diagram, barrier, plane waves, and trajectory lines before drawing the new version. 

const circles = document.querySelectorAll("circle")
const lines = document.querySelectorAll("line")

for (const circle of circles) {
    circle.remove()
}

for (const line of lines) {
    line.remove()
}

The static diagram is then rebuilt in order. First the circular wave peaks are drawn, then the left side is covered, then the barrier is redrawn using the current values of d and slitWidth. Finally the incoming plane waves are drawn again. 

        drawStaticDiagram("#fff", "2")
        coverLeft()
        drawBarrier(d, slitWidth)
        drawPlaneWaves(k0, "#fff", "2")

Since redraw() stops the animation, the stop icon is hidden and the play icon is shown again. 

        stop.style.display = "none"
        play.style.display = "block"

At the end, drawing is set back to false, allowing future redraws. 

        drawing = false
