setup()

In setup we declare and set the value of the variables that define the script. The size of the canvas and its background are set, and setup checks whether the window is in portrait or landscape and sets const horizontal to true or false accordingly. This is only done once, the script includes no support for live resizing of the window.

variables are set: 

            // Numerical inputs
            L = 75
            Nx = 3000
            Nt = 200
            tMax = 20
            p1 = .9
            slider.value = p1
            p2 = 1 - p1

L is the length of the x-axis.
Nx, steps along x-axis (resolution).
p1 initial coefficient for \Psi_1.
p1 sets the initial value of the slider and p2 indirectly. 

            // Physical inputs
            x0 = -40
            p01 = 1
            sigmaP1 = .1
            p02 = -1.25
            sigmaP2 = 0.15
            t = 0.0
            dt = .2
            tFinal = 100

x0, initial mean position of both wavepackets, x0 for \Psi_1 and -x0 for \Psi_2.
p01, p02 sets the momentum for \Psi_1 and \Psi_2 respectively.
sigmaP1 and sigmaP2 does the same for their standard deviation.
t, time initial value.
dt, size of each timestep (temporal resolution).
tFinal, time at which the visualization loops (see draw()).
