draw()

draw is called every frame (60fps), as the name suggests it is responsible for drawing |\Psi|^2 and \operatorname{Re}\Psi. To do so, each frame it sets t = t + \Delta t and calls psiT() with the new t along with the parameters set in setup (initial mean position, momentum, standard deviation) for \Psi_1 and \Psi_2 takes the sum and stores it in three arrays, PsiRe (real part), PsiIm (imaginary part), PsiSq (Psi squared). All of length Nx.
It then draws this array by: 

                beginShape();
                stroke("#fdfdfd");
                strokeWeight(4)
                for (let x = -L / 2, i = 0; x <= L / 2; x += L / Nx, i++){
                    horizontal ? point(x* scaleX,-1 *scaleY * psiRe[i] *.25) : point(-1 *scaleY * psiRe[i] * .25, x* scaleX)
                }
                endShape();
to take \operatorname{Re}\Psi as our example. Setting the color and the radius of each point. Then in a for loop it draws a point at (0 + i \frac{L}{N_x}, PsiRe[i]) reversed if horizontal = true.

reset

draw first checks if the value in the slider is equal to the stored coefficient for \Psi_1 , if it is not t is set to zero and the coefficients are updated. 

            if (slider.value != p1) {
                t = 0
                p1 = slider.value
                p2 = 1 - p1
            }

preparation

The canvas is then cleared, by filling it in rgb(230,230,230) if we don't do this the new graphs are drawn on top of the graphs of all previous frames. It then translates the entire canvas, by default (0,0) is the pixel in the top left, by calling translate(windowWidth / 2, windowHeight / 2) we move origo to the center of the canvas. 

            const scaleY = -1000 * 3;
            const scaleX = 18


Are scalars we multiply the x and y values with to get values that makes sense in pixel space.

update time

lastly it checks if we've reached tFinal, in which case t is set to 0 and the animations starts over again. If not we iterate t += dt and translate origo back to the top left corner. 

            t += dt;
            if (t > tFinal) {
                t=0
            }
            translate(-windowWidth / 2, -windowHeight / 2);
