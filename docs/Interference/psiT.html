psiT()

psiT() returns the value of a free particle Gaussian wavepacket \Psi(x,t) at position x and time t . The wavepacket is initialized with momentum p_0 and spatial standard deviation \sigma_x .
The function implements the analytic solution to the free particle Schrödinger equation: i\frac{\partial \Psi}{\partial t} = -\frac{1}{2}\frac{\partial^2 \Psi}{\partial x^2} where we once again simplify the world slightly by setting \hbar = 1 and m = 1 .
The returned wavefunction is: \Psi(x,t) = \frac{1} { \left(2\pi\sigma_x^2\right)^{1/4} \sqrt{1+i\frac{t}{2\sigma_x^2}} } \; \exp \left( -\frac{(x-p_0t)^2} {4\sigma_x^2\left(1+i\frac{t}{2\sigma_x^2}\right)} \right) \exp(ip_0x) \exp\left(-i\frac{p_0^2}{2}t\right) .
The first exponential term defines the Gaussian envelope of the packet. Since the packet moves with velocity p_0 , the center of the Gaussian shifts according to x \to x - p_0 t .
The factor \exp(ip_0x) gives the packet momentum and oscillatory phase structure, while \exp\left(-i\frac{p_0^2}{2}t\right) is the global time evolution phase.
Unlike a classical particle, the packet also spreads in time. This spreading is encoded in the complex denominator 1+i\frac{t}{2\sigma_x^2} which appears both in the normalization factor and the Gaussian exponent.
The implementation follows the expression almost directly: 

            function psiT(x, t, p0, sigmaX) {
                let i = math.complex(0, 1);
                let A = math.complex(math.sqrt(2 * Math.PI * sigmaX**2));
                let B = math.multiply(2, math.pow(sigmaX, 2))
                B = math.divide(t, B)
                B = math.multiply(i, B)

                let AB = math.add(A, math.multiply(A, B))
                let norm = math.pow(AB, -0.5)

                let denom = math.add(
                    1,
                    math.multiply(i, t / (2 * sigmaX**2))
                );
                let num = -1 * Math.pow(x - p0 * t, 2);
                let exponent1 = math.divide(
                    num,
                    math.multiply(4 * sigmaX**2, denom)
                );
                let term1 = math.exp(exponent1);
                let term2 = math.exp(
                    math.multiply(i, p0 * x)
                );
                let term3 = math.exp(
                    math.multiply(
                        math.multiply(i, -1),
                        math.divide(
                            (math.multiply(math.pow(p0, 2), t)),
                            2
                        )
                    )
                );
                let psi = math.multiply(
                    norm,
                    term1,
                    term2,
                    term3
                );

                return psi;
            }
