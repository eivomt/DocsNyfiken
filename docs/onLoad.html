On load

The functions shown in the flowchart below are called in that order, when the page is loaded or refreshed.

overview

resizeCanvas() sets the width and height of the canvas to match the width and height of the window. drawStaticDiagram() then draws the circular waves as SVG circles. it does this by calculating a maximum radius.
r_{\max}=\sqrt{\left(\frac{h}{2}-\frac{d}{2}\right)^2+L^2}
where;
h = window.innerHeight,
d = distance between slits
L = distance from barrier to screen

Glossing over some unit conversion, it then runs a for loop where radius = lambda, and each iteration radius += lambda, until radius >= maxRadius. Each iteration it creates two new SVG circle elements centered at each of the slits and appends them to
<svg id="staticDiagram"></svg>.

coverLeft() then creates a rectangle which is laid on top of <svg id="staticDiagram"></svg> to hide the left half of the circular wave peaks.

drawBarrier() takes two arguments, d and slitWidth and draws the barrier accordingly by creating three SVG lines. Start and end points for these are given by:
y_c=\frac{h}{2},\quad g=\frac{d}{2},\quad s=\frac{w}{2} y_{\mathrm{top}}^{(1)}=y_c-g-s,\quad y_{\mathrm{bottom}}^{(1)}=y_c-g+s y_{\mathrm{top}}^{(2)}=y_c+g-s,\quad y_{\mathrm{bottom}}^{(2)}=y_c+g+s
Here y_c denotes the vertical center of the window, g half the distance between the slit centers, and s half the slit width. 

        const x = window.innerHeight / 2
        const centerY = window.innerHeight / 2

        const halfGap = inPixels(d / 2)
        const halfSlit = inPixels(slitWidth / 2)

        const topSlitTop = centerY - halfGap - halfSlit
        const topSlitBottom = centerY - halfGap + halfSlit

        const bottomSlitTop = centerY + halfGap - halfSlit
        const bottomSlitBottom = centerY + halfGap + halfSlit

Note that the helper function inPixels(x) has L = 10 hardcoded into itself, changing L is not trivial as this is not the only function which presupposes L = 10. Fixing this is still on the to-do list.

drawPlaneWaves() does essentially the same as drawStaticDiagram did for the circular wave peaks except for creating SVG line elements instead of circles, and places these on top of the rectangle created by coverLeft()

At last renderFig2() is called, making figure 2 the default active figure.
