Bohmian mechanics is the minimal completion of Schrödinger's equation, for a nonrelativistic system of particles, to a theory describing a genuine motion of particles. For Bohmian mechanics the state of a system of N particles is described by its wave function ψ = ψ(q1,...,qN) = ψ(q), a complex (or spinor) valued function on the space of possible configurations q of the system, together with its actual configuration Q defined by the actual positions Q1,...,QN of its particles. The theory is then defined by two evolution equations: Schrödinger's equation
i\hbar\frac{\partial \Psi}{\partial t} = H \Psi
for ψ(t), where H is the nonrelativistic (Schrödinger) Hamiltonian, containing the masses of the particles and a potential energy term, and a first-order evolution equation,

The Guiding Equation:
\frac{dQ_k}{dt} = \frac{\hbar}{mk} \operatorname{Im} [\frac{\Psi^* \partial k \Psi}{\Psi^* \Psi}] (Q_1, ... , Q_N)

Bessel functions

Bessel and Hankel functions are central, as they define \Psi in our MATlab script: 

        % Radial wavefunctions
        %Psi1 = besselh(0, 1, k*R1);   % J_0(k*r)
        %Psi2 = besselh(0, 1, k*R2);   % J_0(k*r)
        %Psi = Psi1 + Psi2;

The besselh(nu, K, Z) function has a bit of a misleading name, it does not in fact return a bessel function but a Hankel function, hence the h I guess. Regardless, let's look at what that means.

order 0

a Bessel function of order 0 has no angular dependence, making it perfectly circularly symmetric. A higher order bessel funciton gives you increasingly intricate angular structure. Pretty sure that's fancy talk for how many nodes there are on the membrane, see The (0,1) Mode

The Hankel function of the first kind and 0th order is a complex-valued combination of the first and second kind Bessel functions;
H^{(1)}_0 (x) = J_0(x) + iY_0(x)
Or in plain language its real part is equal to J_0(x) and its imaginary part is equal to Y_0(x)

J_0 and Y_0 are the circular-wave equivalents of sine and cosine. Separately they behave like standing-wave components. Combined into a Hankel function, they become an outward-propagating cylindrical wave, analogous to how \cos (x) + i \sin (x) = e^{ix} represents a travelling wave.

If we define two of these outward-propagating cylindrical waves with origins separated by a distance d, we have an approximation of the double slit experiment.

U

In bohmian mechanics, the total force acting on a particle is the sum of the negative slope of the classical potential V and the quantum potential U. In the special case of a free particle, the classical potential V = 0 and so the only force acting on the particle is the negative slope of U.

  • the potential is represented as a curved landscape
  • the force points 'downhill'
  • steeper regions correspond to a stronger force

MATlab

        % Parameters
        N = 1000;            % Grid size
        L = 10;              % Physical size (0 to L in x and y)
        k = 5;               % Wave number
        d = 7;               % Distance between centres
        Sp = 98.5;           % Smoothing

        % Create 2D grid
        x = linspace(-L, L, N);
        y = linspace(-L, L, N);
        [X, Y] = meshgrid(x, y);
        R1 = sqrt(X.^2 + (Y+d/2).^2);   % Radial distance from centre 1
        R2 = sqrt(X.^2 + (Y-d/2).^2);   % Radial distance from centre 1


        hx = x(2)-x(1);
        hy = y(2)-y(1);

        % Cutoff
        %Rmin = 2e-1;
        %R1(R1<Rmin) = Rmin;
        %R2(R2<Rmin) = Rmin;

        % Smooth core
        a = 8*max(hx,hy);
        R1eff = sqrt(R1.^2 + a^2);
        R2eff = sqrt(R2.^2 + a^2);
        Psi1 = besselh(0,1, k*R1eff);
        Psi2 = besselh(0,1, k*R2eff);
        Psi = Psi1 + Psi2;

        % Radial wavefunctions
        %Psi1 = besselh(0, 1, k*R1);   % J_0(k*r)
        %Psi2 = besselh(0, 1, k*R2);   % J_0(k*r)
        %Psi = Psi1 + Psi2;

        % For calculating, smoothening and regularizing the quantum potential
        Epsilon = 1e-6;                         % Used in regularization
        % Kernel for Laplacian (5 point stencil)
        wx = 1/(12*hx^2);
        wy = 1/(12*hy^2);
        Kernel_Laplace = [0 0 -wy 0 0; 
            0 0 16*wy 0 0;
            -wx 16*wx -30*(wx+wy) 16*wx -wx;
            0 0 16*wy 0 0;
            0 0 -wy 0 0]; 
        % Kernel for gradient (5 point stencil)
        Kernel_Gradient_X = [1 -8 0 8 -1]*1/(12*hx);
        Kernel_Gradient_Y = [1 -8 0 8 -1].'*1/(12*hy);
        % Kernel for Gaussian-like convolution
        NN = 4/(hx*hy) + 2*(1/hx + 1/hy) + 1;
        Kernel_Gauss = 1/NN*[1/(hx*hy) 1/hy 1/(hx*hy); 
        1/hx 1 1/hx; 1/(hx*hy) 1/hy 1/(hx*hy)];

        % Construct quantum potential
        Rho = abs(Psi).^2;
        Qpot = conv2(Rho, Kernel_Gradient_X, 'same').^2;
        Qpot = Qpot + conv2(Rho, Kernel_Gradient_Y, 'same').^2;
        Qpot = -0.5*Qpot./(Rho+Epsilon).^2;
        Qpot = Qpot + conv2(Rho, Kernel_Laplace, 'same')./(Rho+Epsilon);
        Qpot = -1/4*Qpot;
        MinVal = -500;
        MaxVal = 10;
        Qpot = max(Qpot, MinVal);
        Qpot = min(Qpot, MaxVal);

        % Smoothening by convolution
        Qpot = conv2(Qpot, Kernel_Gauss, 'same');

        writematrix(Qpot, '/Users/eo/Documents/code/Bohmian-Double-Slit-main/Qpot.csv');

        dQdx = conv2(Qpot, Kernel_Gradient_X, 'same'); 
        dQdy = conv2(Qpot, Kernel_Gradient_Y, 'same');

        Fx = -dQdx; 
        Fy = -dQdy;


        nb = 3;   % boundary thickness in grid points (>= stencil radius)


        Fx(1:nb,:)        = NaN;
        Fx(end-nb+1:end,:) = NaN;
        Fx(:,1:nb)        = NaN;
        Fx(:,end-nb+1:end) = NaN;

        Fy(1:nb,:)        = NaN;
        Fy(end-nb+1:end,:) = NaN;
        Fy(:,1:nb)        = NaN;
        Fy(:,end-nb+1:end) = NaN;

        writematrix(dataForce, '/Users/eo/Documents/code/Bohmian-Double-Slit-main/data/Q_gradient_negative.csv');

        y1 = -d/2;
        y2 = d/2;
