Scattering

Imagine, you're throwing a ball against a wall and catching it as it bounces back to you, quite happily. Until suddenly the ball doesn't bounce back, it flies on through the wall. You raise a fist to the sky, 'hey man, that's not how it works', and yet, away it flies.

A visualization of the phenomenon of tunneling / scattering, where parts of the wave function can move through potential barriers of higher energies than it should intuitively be able to overcome. Owing to the exponential, but not instantaneous, decay of the wave function in such areas.

Interestingly, computer circuits are now at the scale where this effect is a barrier (pun intended) to decreasing the size of transistors further. Possibly putting an end to Moores law.

fun facts aside, the visualization is a glorified windows media player. All it does is allow the user to view precomputed mp4 files. The UI allows the user to view the mp4 file corresponding to a particular input of barrier height and initial mean momentum, and to toggle the visibility of a separate mp4 file for the momentum distribution. The fun bit is in the python script which produces them.
