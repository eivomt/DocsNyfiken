measurement

While fire = true measurements are made every .15 seconds. For each measurement the functions called and their order can be read in the flowchart below.

overview

getDetectionEvent samples a point from the probability distribution and returns an event containing position x, y and a timestamp.

The event is passed on to getBackwardTrajectory which iteratively calls velocityAt() with x,y,t updating them in each iteration. initial x is at screen (x=10), the loop works backward, updating time with -dt each iteration. When x or y exceeds the limits of the screen the loop is broken and getBackwardTrajectory() returns a path in the form of a string which can be directly inserted into a SVG element.

burst() calls stagger, passing the path as an argument along with the final Y value e.g. the y value of the measurement at the screen, and the value of bohmian (true or false depending on user input, false by default). If bohmian is false, stagger calls detectElectron, passing the final y value. If bohmian is true an SVG element is created and animated. When the animation is 85% complete detectElectron is called, on completion the SVG element is deleted from DOM and drawn to canvas instead by calling drawPointsToCanvas().

stagger includes support for a more dramatic looking trajectory, to enable it initialize the iterator in the for loop to 0 instead of 4

detectElectron takes one argument (yPercent) and chooses a random x value (within the bounds of its parent element). At this x,y pair it creates a <div> element and animates it to do a little flash to make it easier for the user to see where the new measurement was made. When the animation is finished the <div> element is deleted and a dot is drawn to canvas.
